# Pulso — rádio e mensagens

Projeto Android do Pulso, com TALK por aceite, rádio direto, mensagens, arquivos, contatos e perfil com foto.

## Baixar o APK

Abra a aba **Actions**, entre na execução **Gerar APK de teste** e, quando terminar com sucesso, baixe **Pulso-APK-teste** em **Artifacts**. Extraia o ZIP para encontrar o APK.

A compilação executa automaticamente ao atualizar main e também pode ser iniciada com Run workflow. O APK é de teste; para atualizar instalações existentes preservando os dados, mantenha a mesma chave de assinatura.

## Abrir no Android Studio

Consulte [LEIA-ME.md](LEIA-ME.md). O projeto usa Node 22, Java 21 e SDK Android 36.
